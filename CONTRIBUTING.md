# Contributing to Magento 2 MCP Server

We welcome contributions from the Magento, AI, and MCP developer communities!

## Guidelines
1. Fork the repo and create your branch from `main`.
2. Ensure PSR-12 coding style.
3. Add unit tests for new protocol features or tools in `Test/Unit/`.
4. Run tests: `vendor/bin/phpunit -c phpunit.xml.dist`.
5. Submit a pull request.
